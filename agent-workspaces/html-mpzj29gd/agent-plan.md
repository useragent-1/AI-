**飞机射击小游戏计划**

**文件结构**  
单个 `index.html` 文件，内嵌 CSS 与 JS。

**玩法与特性**  
- 纵版射击，玩家操控飞机在底部移动，自动发射子弹。  
- 敌机从顶部随机出现，向下移动。  
- 击落敌机得分，碰撞敌机或子弹则失去一条命。  
- 生命耗尽游戏结束，显示分数与重玩按钮。  
- 难度逐渐提升（敌机速度、生成频率增加）。

**UI 与画面**  
- Canvas 画布（480×700 或自适应）。  
- 深空星空背景（JS 绘制滚动星星，模拟飞行感）。  
- 顶部显示分数和剩余生命（用爱心图标）。  
- 游戏结束画面：半透明遮罩，居中显示“Game Over”与最终分数，下方“重新开始”按钮。

**交互**  
- 键盘方向键或 WASD 控制飞机移动，限制边界内。  
- 自动射击（子弹间隔 200ms），或按空格键发射。  
- 点击按钮重玩，重置所有状态。

**核心模块（JS）**  
- 玩家对象：位置、移动速度、绘制三角形/飞机图形。  
- 子弹数组：从玩家位置向上移动，碰撞检测。  
- 敌机数组：随机 X 坐标，向下移动，可随机发射子弹（简单版可省略）。  
- 碰撞检测（矩形/圆形简易判定）。  
- 游戏循环 `requestAnimationFrame`：更新、绘制、生成敌机。  
- 状态管理：`gameOver` 标志、`score`、`lives`、`level`。

**可选增强**  
- 吃到道具（如三向子弹、护盾），增加可玩性。  
- 音效（Web Audio 简音）。  
- 手机端支持：虚拟摇杆或触摸拖动。

该计划保证完整可玩，代码量可控，单文件即开即玩。

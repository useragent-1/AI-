计划：像素坦克小游戏（单文件 HTML）

**玩法与特性**  
- 俯视角 2D 像素风格，玩家操控坦克在砖墙迷宫中移动，射击敌方坦克。  
- 关卡：单一固定地图，包含可破坏砖墙与不可破坏钢墙。  
- 敌方 AI：随机巡逻，发现玩家后追逐并开火。  
- 生命与得分：玩家 3 条命，每击杀一辆敌方坦克加 100 分；生命归零游戏结束，显示分数与重玩按钮。  
- 像素美学：使用 Canvas 绘制，坦克、子弹、墙壁均为小尺寸方块，配色复古（军绿、土黄、灰）。

**UI 与交互**  
- 操作：方向键移动，空格键射击（子弹有冷却）。  
- 界面：左上角显示生命（心形图标）与分数；游戏结束显示覆盖层。  
- 音效：无（纯视觉，可后续添加）。  
- 移动端不支持（专注键鼠）。

**文件结构（单个 index.html）**  
- HTML：包含 `<canvas>` 元素及隐藏的游戏结束提示。  
- CSS：内嵌样式，居中 Canvas，暗色背景，像素字体（可选）。  
- JavaScript：游戏循环、玩家输入、碰撞检测、AI、渲染，全部写于 `<script>` 中。  

**实现要点**  
- 地图用二维数组定义，0=空地，1=砖墙，2=钢墙。  
- 坦克用方向 + 速度移动，碰撞检测与墙壁、边界、其它坦克。  
- 子弹直线飞行，击中砖墙销毁墙壁与子弹，击中钢墙仅销毁子弹，击中坦克扣生命。  
- 敌方 AI 简单：随机方向移动，间隔随机转向；若玩家在视野内（直线且无墙阻挡）则朝向玩家移动并射击。  
- 游戏循环：requestAnimationFrame 更新与绘制。  

保证纯静态，只使用一个 HTML 文件内嵌所有资源。

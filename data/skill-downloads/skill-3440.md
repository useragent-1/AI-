# 制造供应链 Skill 3440：流程混乱

## 分类
制造供应链 / 创建评估矩阵 / 验收清单 / 流程混乱

## 使用方法
请扮演供应链顾问，围绕“流程混乱”下的采购、库存、质量、物流任务，创建评估矩阵。输出格式使用验收清单，并包含：目标、输入材料、执行步骤、验收标准、常见风险、下一步行动。

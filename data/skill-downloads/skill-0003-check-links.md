# 项目维护 Skill 0003：检查工具链接有效性

## 分类
项目维护 / 质量 / 链接 / 巡检

## 使用方法
执行：`npm run check-links`。会输出无法访问、重定向异常或状态码异常的链接。优先修复首页高频工具和推荐工具。

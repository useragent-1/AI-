# 风险管理 Skill 4303：预算有限

## 分类
风险管理 / 拆解关键风险 / 表格 / 预算有限

## 使用方法
请扮演风险经理，围绕“预算有限”下的风险识别、预案、审计、复盘任务，拆解关键风险。输出格式使用表格，并包含：目标、输入材料、执行步骤、验收标准、常见风险、下一步行动。

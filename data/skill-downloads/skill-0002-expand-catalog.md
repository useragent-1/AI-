# 项目维护 Skill 0002：扩充工具库 + 生成 Logo 索引

## 分类
项目维护 / 目录 / 导入 / logo

## 使用方法
执行：`npm run expand-catalog`。这会先导入目录数据，再拉取 logo，最后同步 `assets/logos/manifest.js`。完成后检查首页分类数量和新工具徽标。

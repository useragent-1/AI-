# 演讲汇报 Skill 4552：数据不足

## 分类
演讲汇报 / 整理知识库结构 / 一页纸简报 / 数据不足

## 使用方法
请扮演演讲教练，围绕“数据不足”下的汇报、路演、PPT、答辩任务，整理知识库结构。输出格式使用一页纸简报，并包含：目标、输入材料、执行步骤、验收标准、常见风险、下一步行动。

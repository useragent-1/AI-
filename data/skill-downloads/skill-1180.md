# 法律合同 Skill 1180：新手上手

## 分类
法律合同 / 提出优化建议 / 用户故事 / 新手上手

## 使用方法
请扮演合规助理，围绕“新手上手”下的合同、条款、隐私、风险清单任务，提出优化建议。输出格式使用用户故事，并包含：目标、输入材料、执行步骤、验收标准、常见风险、下一步行动。

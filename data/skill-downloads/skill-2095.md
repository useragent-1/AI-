# 低代码 Skill 2095：流程混乱

## 分类
低代码 / 提出优化建议 / 用户故事 / 流程混乱

## 使用方法
请扮演低代码顾问，围绕“流程混乱”下的表单、自动化、内部工具任务，提出优化建议。输出格式使用用户故事，并包含：目标、输入材料、执行步骤、验收标准、常见风险、下一步行动。

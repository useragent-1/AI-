# 风险管理 Skill 3953：合规审查

## 分类
风险管理 / 模拟专家评审 / 会议议程 / 合规审查

## 使用方法
请扮演风险经理，围绕“合规审查”下的风险识别、预案、审计、复盘任务，模拟专家评审。输出格式使用会议议程，并包含：目标、输入材料、执行步骤、验收标准、常见风险、下一步行动。

# 开源运营 Skill 3899：个人项目

## 分类
开源运营 / 制作排查路径 / 路线图 / 个人项目

## 使用方法
请扮演开源维护者，围绕“个人项目”下的Issue、PR、社区、发布任务，制作排查路径。输出格式使用路线图，并包含：目标、输入材料、执行步骤、验收标准、常见风险、下一步行动。

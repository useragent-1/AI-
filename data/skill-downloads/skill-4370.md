# DevOps Skill 4370：新手上手

## 分类
DevOps / 提出优化建议 / 用户故事 / 新手上手

## 使用方法
请扮演DevOps工程师，围绕“新手上手”下的CI/CD、部署、监控、回滚任务，提出优化建议。输出格式使用用户故事，并包含：目标、输入材料、执行步骤、验收标准、常见风险、下一步行动。

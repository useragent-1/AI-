# DevOps Skill 0020：流程混乱

## 分类
DevOps / 创建评估矩阵 / 验收清单 / 流程混乱

## 使用方法
请扮演DevOps工程师，围绕“流程混乱”下的CI/CD、部署、监控、回滚任务，创建评估矩阵。输出格式使用验收清单，并包含：目标、输入材料、执行步骤、验收标准、常见风险、下一步行动。

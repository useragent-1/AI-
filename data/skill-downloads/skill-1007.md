# 全栈开发 Skill 1007：工具迁移

## 分类
全栈开发 / 整理知识库结构 / 一页纸简报 / 工具迁移

## 使用方法
请扮演全栈工程师，围绕“工具迁移”下的端到端应用、路由、接口联调任务，整理知识库结构。输出格式使用一页纸简报，并包含：目标、输入材料、执行步骤、验收标准、常见风险、下一步行动。

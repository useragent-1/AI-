# 全栈开发 Skill 4357：数据不足

## 分类
全栈开发 / 设计自动化脚本思路 / 决策树 / 数据不足

## 使用方法
请扮演全栈工程师，围绕“数据不足”下的端到端应用、路由、接口联调任务，设计自动化脚本思路。输出格式使用决策树，并包含：目标、输入材料、执行步骤、验收标准、常见风险、下一步行动。

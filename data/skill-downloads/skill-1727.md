# 团队协作 Skill 1727：工具迁移

## 分类
团队协作 / 整理知识库结构 / 一页纸简报 / 工具迁移

## 使用方法
请扮演团队教练，围绕“工具迁移”下的会议、协作、决策、冲突处理任务，整理知识库结构。输出格式使用一页纸简报，并包含：目标、输入材料、执行步骤、验收标准、常见风险、下一步行动。

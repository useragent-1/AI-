# 项目维护 Skill 0001：批量拉取站点 Logo

## 分类
项目维护 / 脚本 / 数据 / logo

## 使用方法
在项目根目录执行：`npm run fetch-logos`。如需提高并发：`$env:LOGO_CONCURRENCY=32; npm run fetch-logos`（PowerShell）。输出前先检查日志并确认失败域名。
